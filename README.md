# Piccolo

Este proyecto es una aplicación web desarrollada con Python, Streamlit y SQLite, diseñada para actuar como un asistente integral que facilite la organización diaria y el acceso a la tecnología de las personas mayores.

## 🚀 Descripción del Proyecto
El objetivo principal es reducir la brecha digital, ofreciendo una interfaz amigable e intuitiva. El sistema permite gestionar recordatorios (por ejemplo, toma de medicamentos o citas médicas) y organizar información útil de manera simplificada.

## 🛠️ Tecnologías Utilizadas
- *Lenguaje:* Python 3.x
- *Framework Web:* [Streamlit](https://streamlit.io/)
- *Base de Datos:* SQLite (Almacenamiento local de datos)
- *Control de Versiones:* Git / GitHub
